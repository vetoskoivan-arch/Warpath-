# Warpath Inventory — Windows MVP

Приложение для Windows 10/11. Открывает скриншоты Warpath (PNG/JPG/WEBP), захватывает экран, извлекает OCR-подсказки (числа и текст), позволяет подтвердить название/количество/категорию, сохраняет записи локально и экспортирует CSV.

**Ограничение:** распознавание предметов по иконкам не реализовано; OCR может ошибаться и находить посторонние числа. Не используйте найденные значения без проверки. Захват работает для видимого экрана; если игра перекрывает захват, переключите её в оконный режим или используйте скриншоты. Никакого подключения к игровому аккаунту или серверу нет.

## Получить установщик EXE через GitHub

1. Создайте новый репозиторий GitHub и загрузите **всё содержимое** этой папки, включая `.github/workflows/windows-installer.yml`.
2. Откройте вкладку **Actions** → **Build Windows installer** → **Run workflow**.
3. После успешной сборки откройте запуск, раздел **Artifacts**, скачайте `WarpathInventorySetup.zip` и извлеките `WarpathInventorySetup.exe`.
4. Запустите EXE на Windows. Если Windows SmartScreen предупреждает о неподписанном приложении, проверьте происхождение файла перед запуском.

GitHub Actions требует разрешённых workflows; возможны ограничения тарифа. Сборка на Windows использует Python, PyInstaller, Tesseract и Inno Setup. Движок OCR устанавливается внутрь приложения, поэтому отдельно Python и Tesseract на компьютере не нужны.

## Запуск исходников

Установите Python 3.11 и Tesseract OCR, затем `pip install -r requirements.txt` и `python app.py`.

## Хранение данных

`%APPDATA%\WarpathInventory\inventory.json` (локально на ПК). При повторном добавлении предмета той же категории количество **заменяется**, а не складывается — это защищает от двойного подсчёта при перекрывающихся скриншотах.

## Безопасность

Нет логина Warpath, чтения памяти процесса, внедрения в игру и сетевого взаимодействия. Все данные остаются на ПК.
